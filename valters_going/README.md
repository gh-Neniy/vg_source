Нужно переработать все координаты и закрепить локации (refine), также и декор, и работу

logic - проверки, активирующие скрипт, если они выполняются
- logic/main - те проверки, которые выполняются всегда, независимо от состояния карты
mob - мобы, боссы, сущности-предметы
item - предметы
script - все скрипты (например, течение первого задания является скриптом, открытие дверей на спавне)

Логическая схема:
0 - не было запуска
1 - запущен
2 - выполнен

#timer data - общий для всех таймер
timer - таймер, который свой для каджой сущности
