Архитектура:
data - общий scoreboard

#progress - для отслеживания прогресса игроков
#timer - таймера для катсцен и заданий
#timer_active - включен ли таймер

Глобально все функции распределены по 4 директориям:
1) logic - проверки, активирующие скрипт, если они выполняются
- logic/main - те проверки, которые выполняются всегда, независимо от состояния карты
2) mob - мобы (как обычные мобы, так и боссы, так и сущности-предметы)
3) item - предметы, которые только есть на карте
4) script - все скрипты (например, течение первого задания является скриптом, открытие дверей на спавне)

Если для функции <name> нужны блоки кода, то они расположены в <name>/<block_number>
