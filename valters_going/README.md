logic - проверки, активирующие скрипт, если они выполняются
- logic/main - те проверки, которые выполняются всегда, независимо от состояния карты
mob - мобы, боссы, сущности-предметы
item - предметы
script - все скрипты (например, течение первого задания является скриптом, открытие дверей на спавне)

Логическая схема:
0 - не было запуска
1 - запущен
2 - выполнен

Последательность скриптов со временем:
1) скример на спавне с дверью
2) котел
3) призыв Вальтера
4) появление зомби - нулевое задание
5) открытие магазина
6) появление первого задания
7) течение первого задания
8) открытие работы
9) появление второго задания
10) течение первого задания
