### Что это  

В этом репозитории хранится исходный код на языке Neniy для моей карты в майнкрафте. Здесь прописана вся логика, настроены катсцены, скрипты и кастомные мобы.

### Для чего это нужно  

Код универсален, то есть компилируется под любую версию, начиная с 1.21.11. Переносить сотни и тысячи файлов с mcfunction вручную не приходится.
